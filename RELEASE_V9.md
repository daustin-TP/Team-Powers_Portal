# Team Powers Portal v9

This release refreshes the portal UI with the supplied Team Powers logo and the accessible Domino's brand palette.

- Adds the Team Powers logo to sign-in, loading, desktop navigation, mobile navigation, and the browser tab.
- Uses Dough neutrals with accessible blue/red and Lava text colors.
- Replaces the hard-coded dashboard calendar with the user's current local date.

No Supabase SQL migration is required for this release. Upload the complete v9 package to the GitHub repository root and allow Cloudflare to deploy the `main` branch.
