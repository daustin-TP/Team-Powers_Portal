# Team Powers Portal v12

- Employees and managers see only Maintenance and Technology requests they submitted.
- Supervisors, accounting, and administrators see all Maintenance and Technology requests.
- The same visibility restrictions protect ticket progress notes and attached images.
- Personal ticket pages are labeled as the user's own support history.

Run `supabase/migrations/202608180011_support_ticket_visibility.sql` before testing role visibility, then deploy the complete v12 package from the GitHub repository root.
